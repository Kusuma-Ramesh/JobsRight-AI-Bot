# JobsRight AI Bot

This directory contains the Phase 1 project skeleton for a scalable Manifest V3 Chrome extension.

## Architecture overview
- Manifest V3 entry points for background, content scripts, popup, and options pages.
- Modular folders are reserved for future features such as job scanning, AI analysis, resume generation, application filling, bulk apply integration, screenshot management, local storage, logging, settings, and popup UI.
- No business logic or runtime behavior is implemented in this phase.

## Placeholder intent
Each file in this scaffold exists to define structure, module boundaries, and future extension points.
